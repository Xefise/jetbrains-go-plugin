Reports declarations and calls written the C#, Java or JavaScript way, which Go does not accept:
  • a type before the name: []float64 arr, int a := 0, func f(int n);
  • a spread before the argument: f(...xs).

Quick-fixes rewrite them as arr []float64, a := 0 or var a int = 0, f(xs...).

Fields and parameters named string or error are valid Go and are not reported.
